2. ALGORITHM LOGIC & FUNCTION SPECIFICATION
   function constructPDFURL(roll, dob):
       input: roll (numeric string >= 5 digits), dob (string YYYY-MM-DD)
       last5Roll = roll.slice(-5)
       dobParts = dob.split('-')
       month = dobParts[1]
       day = dobParts[2]
       dateMonth = day + month           // 4 digits (DDMM)
       pdfCode = last5Roll + dateMonth   // 9 digits (e.g. 85468 + 3012 = 854683012)
       primaryUrl = "Result_PDFs/" + pdfCode + ".pdf"
       fallbackUrl = "https://raw.githubusercontent.com/nationalacademyonline/.in/main/CEB/Result_PDFs/" + pdfCode + ".pdf"
       downloadName = "Result_" + pdfCode + ".pdf"
       return { primaryUrl, fallbackUrl, downloadName }
