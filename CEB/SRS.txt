1. INTRODUCTION
   1.1 Purpose
       This document defines the software requirements for the Central Examination Board Result Web Application. The system enables Class 9 and Class 10 students to search and retrieve their official secondary school marksheets hosted on GitHub.
   1.2 Scope
       Targeted at Class 9 and Class 10 secondary school examinations. All PDF certificates are accessed via a deterministic mathematical algorithm matching user-input Roll Number and Date of Birth.

2. PURPOSE AND SCOPE
   - Public online portal for "Central Examination Board Result".
   - Class 9 & Class 10 Secondary Education.
   - Numeric Roll Number input (digits only, minimum 5 digits, e.g. 22285468).
   - DOB calendar selector system (HTML5 Date Picker).
   - Direct verified download & preview of official PDF marksheets (`Result_PDFs/{pdfCode}.pdf` with fallback to GitHub raw storage).

3. MATHEMATICAL PDF URL ALGORITHM
   3.1 Inputs:
       - Roll Number (numeric string >= 5 digits)
       - Date of Birth (YYYY-MM-DD format from date picker)
   3.2 Derivation Formula:
       - Code = (Last 5 digits of Roll Number) + (First 4 digits of DOB: Day DD + Month MM)
   3.3 Target URL Construction:
       - Primary: "Result_PDFs/" + Code + ".pdf"
       - Fallback: "https://raw.githubusercontent.com/nationalacademyonline/.in/main/CEB/Result_PDFs/" + Code + ".pdf"
       - Clean Download Filename: "Result_" + Code + ".pdf"
   3.4 Example:
       - Roll: 22285468, DOB: 30-12-2016 -> Day: 30, Month: 12 -> Code: 854683012 -> File: Result_854683012.pdf
